1. Project Overview

This project develops a deep learning model for pixel-level Land Use / Land Cover (LULC) classification using Sentinel-1 VV and VH radar imagery. The model is based on a Small U-Net architecture and predicts nine land-cover classes.

8. Critical Discussion & Limitations

  • The model achieves 53.50% test accuracy and 30.55% mIoU, demonstrating meaningful predictive capability above the 17.71% majority baseline.
  • Performance varies substantially between classes. Urban/Built-up, Cropland and Water perform considerably better than minority classes such as Wetland and Shrubland.
  • The prediction distribution indicates a tendency toward dominant classes, especially Cropland and Urban/Built-up.
  • The January 2025 Lagos prototype shows strong Urban/Built-up dominance, which should be interpreted cautiously because of distribution shift.
  • The comparison with ESA WorldCover 2021 provides an independent reference for sanity checking but cannot be considered a formal ground-truth accuracy measurement.
  • Future improvements could include class balancing, additional training data for minority classes, longer training, augmentation, improved normalisation, and temporal/multi-season Sentinel-1 observations.

9. Final Project Summary

Conclusion:

The developed Sentinel-1 LULC classification pipeline successfully covers dataset preparation, model training, quantitative evaluation, and inference on a real-world January 2025 Lagos Sentinel-1 composite. The Small U-Net achieves 53.50% test accuracy and 30.55% mean IoU, outperforming the 17.71% majority baseline. The prototype demonstrates the feasibility of applying the trained model to unseen satellite imagery, while the independent ESA WorldCover comparison provides an external qualitative sanity check. The main limitation is uneven performance across land-cover classes and the observed distribution shift between training data and the real-world prototype imagery.
